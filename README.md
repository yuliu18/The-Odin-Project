## 📖 About

[The Odin Project](https://www.theodinproject.com/) is a free, open-source curriculum for learning full-stack web development. This repository collects my solutions as I progress through the lessons — each project lives in its own folder with its own code and notes.

The goal is not just to finish exercises, but to **understand the fundamentals**: how the browser works, how JavaScript really behaves, and how to write clean, maintainable code.

## 🚀 Running a project

Each project is self-contained. Clone the repo and open the project's `index.html` in your browser:

```bash
git clone git@github.com:yuliu18/The-Odin-Project.git
cd The-Odin-Project/RockPaperScissors
open index.html   # macOS — or just double-click the file
```

For console-based projects, open the browser DevTools (`Cmd+Option+J` / `Ctrl+Shift+J`) to see the output.
